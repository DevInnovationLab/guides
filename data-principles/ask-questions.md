## Ask questions

<div class="ref-summary" markdown="1">
DIL's process for resolving a coding problem that cannot be solved immediately.
</div>

### Process

1. Search for an existing answer: paste the error message into a search engine and check the relevant help file. Most questions already have an answer on Stack Overflow or a similar forum.
2. If no answer is found within about fifteen minutes, ask in DIL's `#_analytics_help` Slack channel or open a question on [Stack Overflow](https://stackoverflow.com/){:target="_blank"}.

### A complete question states

- The task being attempted.
- The expected result.
- What has already been tried.
- The exact error message or unexpected output produced.
- The software version and system details.
- A reproducible example or mock dataset, where possible.
